8 Puzzle Problem
Project for CS4200
This project uses A* search to solve the 8-puzzle problem. There are two heuristic functions that needed to be implemented: h1 = the number of misplaced tiles and h2 = the sum of the distances of the tiles from thier goal positions.

To run the code, you simply follow the instructions on the screen. When you run it, it will display a menu option for the user with two choices: single test puzzle or exit. If the user selects the Single Test Puzzle, it will give them a choice between a random puzzle or their own input. A random puzzle will create a puzzle and you would just choose which heuristic you want (both will show at the end). User Input will prompt the user to enter thier own puzzle. You can enter the numbers for each row as seen on the screen. Again, you will be able to choose between two heuristics and it will show the search cost/time. The program will keep running until the user selects the exit option.
